# 📊 Performance, Rendering, and Memory Audit Log (`PERFORMANCE.md`)

This document details the comprehensive audit of **rendering efficiency (rebuilds/repaints)**, **RAM object allocation (Dart VM Heap Profiling)**, **shader/canvas animations (`CustomPainter` / `BackdropFilter`)**, and **Inter-Isolate Communication (IPC)** performed on **Tachyon** on Linux (extensible to Windows and Android), along with all architectural optimizations applied and comparative before-and-after benchmarks.

## 4. RAM Object Lifecycle & Graph Optimization

1. **Elimination of `_Float32List` in [`WaveformCodec`](../lib/shared/utils/waveform_codec.dart):**
   - Previously, Base64 was decoded to `Uint8List(100)` and converted to a separate `Float32List(100)` per track (`1,496` instances = `631.1 KB`).
   - Replaced by `_Uint8WaveformList extends ListBase<double>`, a zero-copy unmodifiable view directly over decoded bytes that calculates `_bytes[index] * (1.0 / 255.0)` on demand. This eliminated **100% of `_Float32List` allocations** from the heap while preserving the `List<double>? waveform` interface.

2. **Zero-Copy Views & Collection Deduplication in [`LibraryStore`](../lib/features/library/data/library_store.dart):**
   - Getters `tracks`, `albums`, `artists`, `genres`, `playlists`, and `likedTrackIds` previously called `List.unmodifiable(...)` on every access. Replaced with lazy cached views `UnmodifiableListView` and `UnmodifiableSetView` (`dart:collection`), invalidated strictly on catalog mutation (`_invalidateViews()`).
   - During `hydrateFromSnapshot`, `Track.artists` and `Track.genres` backing lists were changed from `_GrowableList` to `const []` or `List.of(..., growable: false)`, eliminating **over 55,000 array instances**.
   - Interned strings (`internString`) for `thumbnailHash` and `codec` (e.g. `"FLAC"`, `"MP3"`, `"M4A"` and shared album cover hashes), removing **15,899 duplicate `_OneByteString` instances** (`-992 KB`).
   - Pre-computed lowercase sort keys in $O(N)$ before sorting, avoiding repeated `.toLowerCase()` transformations inside the $O(N \log N)$ comparator.

3. **Canonical Pointer Re-binding in [`PlaybackController.onLibraryStoreUpdated`](../lib/features/playback/presentation/playback_controller.dart):**
   - Active queue tracks in `_state.playables` are immediately re-linked to canonical `LibraryStore` pointers upon `loadLibrary()`, maintaining exactly **1,496 `Track` instances** in memory (`identical() == true`).

4. **I/O Discovery Optimization in [`MetadataService`](../lib/core/backend/services/metadata_service.dart):**
   - In `_discoverFilesLocal`, replaced `await entity.stat()` with synchronous `entity.statSync()` yielding the event loop every 64 files (`Future.delayed(Duration.zero)`), preventing 1,502 concurrent asynchronous tasks from overwhelming the Dart I/O thread pool.

## 5. Minimized Mode Architecture (Multiplatform & Native GTK)

To minimize CPU and memory consumption when Tachyon is in the background or minimized, a 3-layer reactive pipeline is implemented:

1. **Native Detection (`SystemMediaService` & Linux Runner):**
   - **Flutter Framework:** Combined `AppLifecycleListener` (`onHide`/`onPause` $\to$ `true`, `onShow`/`onResume` $\to$ `false`) and `WidgetsBindingObserver`.
   - **Linux GTK3 (`linux/runner/my_application.cc`):**
     - Titlebar minimize button hooked via `gtk_container_forall` listening to `clicked` on buttons with CSS class `"minimize"` or icon `"window-minimize-symbolic"`.
     - Window state events monitored (`GDK_WINDOW_STATE_ICONIFIED | GDK_WINDOW_STATE_WITHDRAWN`), supporting Wayland and X11 seamlessly.
     - Dispatches through platform channel `dev.chomusuke.tachyon/window_state` via `onMinimizedChanged(bool)`.
   - **Windows (`windows/runner/flutter_window.cpp`):**
     - Hooks `WM_SIZE` with `SIZE_MINIMIZED` and `WM_ACTIVATE` with `WA_INACTIVE`.

2. **Visual Suspension & Cache Purge in UI Isolate:**
   - **Background & Lyrics Suspension:** Hides `AppBackground` to release GPU textures. `NowPlayingScreen` sets `LyricsController.setLyricsViewVisible(false)`, stopping timers and remote lyrics RPCs.
   - **Skia Image Cache Eviction:** Calls `PaintingBinding.instance.imageCache.clear()`, `clearLiveImages()`, and sets `Skia.setResourceCacheMaxBytes(0)`.
   - **OS Memory Reclamation:** Invokes `MemoryOptimizer.trim(aggressive: true)`.

3. **IPC Throttling & Computation Suspension in Backend Isolate:**
   - **Throttled Position Stream:** Position delivery slows from 25 Hz (40 ms) to 0.2 Hz (5,000 ms), eliminating 125 cross-isolate messages every 5 seconds.
   - **Visualizer Suspension:** Halts FFT calculations and wave generation in the backend.
   - **Database Memory Shrink:** Executes `AppDatabase.shrinkMemory()` (`PRAGMA shrink_memory;`) to release unreferenced SQLite cache pages.
   - **Restoration:** Restoring the window immediately sends the exact current playback position and resumes the 25 Hz ticker.

## 6. Swipe-to-Dismiss Gesture Performance (`NowPlayingScreen`)

- **Previous Bottleneck:** Rebuilding `Scaffold` conditionally when crossing drag offset threshold caused Flutter to recreate the widget hierarchy mid-gesture, dropping the active `VerticalDragGestureRecognizer` and causing visible stuttering.
- **Optimization:**
  1. Decoupled drag offset into `ValueNotifier<double> _screenDragOffset`.
  2. Wrapped transformations permanently via `_wrapWithDragTransform(child)` using `ValueListenableBuilder<double>`.
  3. `ClipRRect` operates with `Clip.none` and `BorderRadius.zero` at rest (zero GPU overhead), toggling to `Clip.antiAlias` only during active dragging (`isDragging == true`) without rebuilding the `Scaffold`.
  4. 60/120 FPS gesture updates mutate only the composition layer transformation matrix with zero widget rebuilds.
